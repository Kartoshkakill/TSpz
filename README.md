# TSpz

🔹 Спеціальні мови програмування (TypeScript)
У цій гілці зберігаються лабораторні та навчальні матеріали з курсу "Спеціальні мови програмування", виконані мовою TypeScript.
Основна мета — продемонструвати базові та просунуті можливості TS:

робота з типами та інтерфейсами;

модулі та простори імен;

функціональне програмування;

обробка помилок;

приклади практичних задач.

Цей репозиторій може стати в нагоді як студентам, так і всім, хто хоче швидко увійти в світ TypeScript.
